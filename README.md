# Audio Playlist

GitHub Pages上で動作する個人用の簡易音声プレイリストアプリです。サーバーへ音声データを送信せず、ブラウザ内で再生・トリミング位置管理・プレイリスト保存を行います。

## 対応形式

- MP3
- WAV
- AAC
- M4A

## 主な機能

- 複数音声ファイルの追加
- 曲順変更・削除
- 再生、一時停止、停止、シーク
- 再生位置の数値入力（0.05秒単位）
- 曲ごとの開始・終了位置設定
- 現在のtrim範囲の試聴
- 同じ音声ファイルをプレイリスト内で複数回使用可能
- オフ / リストリピート / 指定区間リピート
- 指定区間を1曲だけにした1曲リピート
- 指定区間のみのランダム再生
- 曲ごとの重み付き抽選（0以上のfloat）
- 次曲の1曲先読み
- 同じassetを連続使用する場合の音声データ流用
- ローカル保存・読み込み
- playlist.json + 音声ファイルをまとめたZIP保存・読み込み

## JSON形式

トップレベルは以下の構成です。

```json
{
  "format": "audio-playlist",
  "version": 2,
  "playlist": {},
  "settings": {},
  "assets": [],
  "tracks": []
}
```

`assets` は音声ファイルそのもの、`tracks` はプレイリスト上の各登場位置です。したがって同じassetを複数trackから参照できます。trimとweightはtrack単位で保持します。

ZIPは以下の構成です。

```text
playlist.zip
├── playlist.json
└── audio/
    ├── asset-id.mp3
    ├── asset-id.wav
    └── ...
```

プレイリストに同じassetが複数回登場しても、ZIP内の音声ファイルは1回だけ格納します。

## バージョン互換

現在のJSONバージョンは `2` です。旧バージョン1のデータを読み込むと、内部でバージョン2へ正規化され、次回のローカル保存・ZIP保存ではバージョン2として出力されます。

v1の「末尾のみ1曲リピート」は「指定区間リピート + 末尾1曲」に変換します。v1の「1曲リピート」は対象曲の選択状態を保存していなかったため、移行時は先頭曲を1曲ループの対象とします。

## GitHub Pages

`index.html`, `style.css`, `app.js` を同じディレクトリに置き、GitHub Pagesから公開してください。

ZIP処理にはCDNからJSZipを読み込んでいます。
